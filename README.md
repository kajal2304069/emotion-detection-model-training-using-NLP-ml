# 🧠 Emotion Analysis NLP Project

This project analyzes human emotions from text using NLP and Machine Learning.

## 🚀 Features

- Emotion Detection from Text
- TF-IDF Vectorization
- SVM Machine Learning Model
- Attractive Streamlit UI
- Real-time Emotion Prediction
- Confidence Score
- Emotion Emojis

---

## 🛠 Technologies Used

- Python
- NLP
- Scikit-learn
- TF-IDF
- Streamlit
- Pandas
- NumPy

---

## 📂 Project Structure

```bash
Emotion-Analysis-Project/
│
├── app.py
├── emotion_model.pkl
├── tfidf_vectorizer.pkl
├── requirements.txt
├── README.md
```

---

## ▶ How to Run

Install dependencies:

```bash
pip install -r requirements.txt
```

Run Streamlit app:

```bash
streamlit run app.py
```
